# CodeAlpha Social Media Platform

A basic full-stack social media platform developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- User registration and login
- User profile
- Edit profile
- Create posts
- Display posts
- Like system
- Comments
- Follow system
- SQLite database
- Express.js backend

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- SQLite

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Go to the backend folder:

```bash
cd backend
5. Install dependencies:

```bash
npm install
6. Start the backend server:

```bash
node server.js
7. Open the website in your browser.
